## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Cridan/personal-portfolio
```

Navigate into the project:

```bash
cd personal-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
